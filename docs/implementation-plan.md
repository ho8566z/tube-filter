# 구현 순서 (Codex 위임 단위)

각 단계는 한 번에 하나씩 위임한다. 기능 ID는 `spec/05_기능_목록.md`, 상세는 `spec/06_기능_명세서.md`·`07_필터_명세서.md`·`08_API_명세서.md`.
