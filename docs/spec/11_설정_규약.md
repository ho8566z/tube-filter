|---|---|---|---|
| 모듈·포트 | 웹 앱 | FastAPI + Uvicorn, 포트 8000 | 화면(HTML)과 JSON API를 같이 제공 |
|  | DB | SQLite 파일(data/tubefilter.db) | 환경변수 DATABASE_URL로 바꿀 수 있음 |

|  | SESSION_SECRET | 세션 서명 키(32자 이상 임의 문자열) | - |
|  | QUOTA_DAILY_LIMIT / QUOTA_SOFT_LIMIT | 10000 / 9000 | 소프트 상한 도달 시 새 API 호출 차단(quota-004) |
|  | CACHE_SEARCH_TTL_HOURS / CACHE_STATS_TTL_HOURS / CACHE_MAX_DAYS | 6 / 24 / 28 | cache-001, cache-002, cache-003. CACHE_MAX_DAYS는 30을 넘기지 말 것(정책) |
|  | LIMIT_SEARCH_GUEST_PER_DAY / LIMIT_SEARCH_USER_PER_DAY | 5 / 20 | IP당(비회원)·계정당(회원) 하루 신규 검색 횟수(quota-006). 캐시 적중은 제외 |
|  | LIMIT_SEARCH_PER_MIN / LIMIT_OTHER_PER_MIN | 10 / 60 | IP당 분당 요청 수(sec-006) |
| YouTube API 쿼터 비용 | search.list | 100 units/호출, 호출당 최대 50개, 쿼리당 최대 약 500개 | 후보 수집(FNC-S-003) |
|  | videos.list | 1 unit/호출, id 최대 50개 | part=snippet,contentDetails,statistics,status |
|  | channels.list | 1 unit/호출, id 최대 50개 | part=snippet,statistics,contentDetails |
|  | playlistItems.list | 1 unit/호출, maxResults 최대 50 | part=contentDetails, 채널의 uploads 재생목록 |

|  | 일일 할당량 | 기본 10,000 units, 태평양 시간(PT) 자정 초기화 | 서머타임 반영(America/Los_Angeles). 한국 시간으로는 17:00(서머타임 아닐 때) 또는 16:00 |
| 공통 API 규칙 | 경로 | 모든 API는 /api/v1/ 로 시작 | 화면(HTML) 경로는 / 로 시작 |
|  | 데이터 형식 | 요청·응답 본문은 JSON(UTF-8). 필드 이름은 camelCase | CSV·HTML은 예외 |
|  | 시각 형식 | ISO-8601, 한국 시간 오프셋 포함. 예: 2026-11-10T14:03:00+09:00 / 날짜만: 2026-11-10 | DB는 UTC 저장, 응답할 때 KST로 변환(nfr-003) |
|  | 기간 조회 | from 이상 ~ to 미만(반열린 구간) | 게시 기간 필터에도 적용 |
|  | 페이지 | 요청: page(0부터), size(10/20/50, 기본 20). 응답: {items, page, size, totalElements, totalPages} | 목록 API 공통 |
|  | 범위 값 | {"min": 숫자, "max": 숫자}. 둘 중 하나만 있어도 됨, 경계 포함 | min>max면 400 INVALID_RANGE |
|  | 오류 응답 | {"code": "INVALID_RANGE", "message": "최소값이 최대값보다 클 수 없습니다.", "fieldErrors": [{"field": "video.views", "message": "…"}]} | code는 영문 대문자 상수, message는 화면에 그대로 띄울 수 있는 한국어. fieldErrors는 입력 검증 오류일 때만 |
|  | 인증 오류 | 로그인 안 됨: 401(API) / 로그인 화면으로 이동(화면). 권한 없음: 403 | API 요청 여부는 경로(/api/)로 판단 |
|  | CSRF | 상태 변경 요청에 X-CSRF-Token 헤더 필수. 화면은 meta 태그로 토큰을 받음 | sec-005 |
| 세션 | 쿠키 | TF_SESSION, HttpOnly, SameSite=Lax. HTTPS 배포 시 Secure | 서명 쿠키 세션(서버 저장 없음) |

|  | 비밀번호 | 8~64자, 영문과 숫자를 각각 1자 이상 | bcrypt 저장 |
|  | 키워드 | 1~100자 | - |

|  | 조회수·좋아요·댓글 | 0 이상 정수. 화면 ▲▼ 단위 100 | 직접 입력은 1 단위 |
|  | 비율(%) | 0 ~ 100 (구독자 대비 조회수는 상한 없음), 소수점 둘째 자리 | - |

|  | 태그 | 포함·제외 각각 최대 30개, 태그당 1~50자 | 소문자, 앞뒤 공백 제거, 중복 제거 |
|  | 제목·설명 단어 | 포함·제외 각각 최대 20개, 단어당 1~50자 | - |
|  | 프리셋 이름 | 1~30자, 회원당 최대 30개 | - |
|  | 즐겨찾기 | 회원당 최대 200개 | - |

|  | 채널 활동 조회 한도 | 한 번의 검색에서 최대 50채널 | 초과 채널은 ‘조회 한도 초과’로 표시하고 조건 판정에서 제외 |
