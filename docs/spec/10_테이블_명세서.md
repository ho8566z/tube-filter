테이블 명세서 (tube-filter)

공통 규칙<br>- SQLite 3, SQLAlchemy 2.x 모델로 정의하고 Alembic으로 마이그레이션한다. 다른 DB(MySQL 등)로 옮겨도 되도록 DB 전용 기능을 쓰지 않는다.<br>- 날짜·시각은 UTC로 저장하고 표시할 때 한국 시간(KST)으로 바꾼다(쿼터 일자 usage_date는 PT 날짜).<br>- 조건(conditions)·목록(video_ids)·태그 등은 JSON 문자열(TEXT)로 저장한다.<br>- COMMENT: 칼럼에 담기는 데이터. 비고: 칼럼의 쓰임과 관련 요구사항.<br>- YouTube에서 가져온 데이터(video_cache, channel_cache)는 fetched_at 기준 28일이 지나면 삭제한다(cache-003).
